# discord-coper

[🇬🇧 English](README.md) · **🇷🇺 Русский**

Discord-бот, который копирует **структуру** сервера — роли, категории, каналы
и права доступа к каждому каналу — и воссоздаёт её на другом сервере.

По сути это та же идея, что встроенные в Discord *Шаблоны сервера*, но здесь
переносятся ещё голосовые, трибунные и форумные каналы. Инструмент рассчитан на
серверы, которыми вы управляете сами: например, переезд сообщества на новый
сервер или создание тестовой копии.

Есть **две взаимозаменяемые реализации** — выбирайте стек, который вам ближе:

| | Язык | Библиотека | Папка |
| --- | --- | --- | --- |
| 🐍 | Python 3.10+ | [discord.py](https://discordpy.readthedocs.io/) 2.x | [`python/`](python/) |
| 🟢 | Node.js 18+ | [discord.js](https://discord.js.org/) 14.x | [`node/`](node/) |

Обе версии создают и читают **один и тот же формат конфига**, поэтому можно
сделать `/copy` Python-ботом, а `/paste` — Node-ботом, и наоборот.

## Как это работает

1. Добавьте бота на **исходный** сервер и выполните `/copy`.
   Бот снимет слепок сервера и ответит коротким **ID конфига**, а также
   приложит сам конфиг в виде JSON-файла (тот самый «файл конфигурации
   сервера»: роли с их правами и порядком, каналы и кто какие из них видит).
2. Добавьте бота на **целевой** сервер и выполните `/paste id:<этот-ID>`.
   После подтверждения бот воссоздаст всю структуру.

### Команды

| Команда | Кто может выполнить | Что делает |
| --- | --- | --- |
| `/copy` | Участники с правом **Управление сервером** | Снимает слепок текущего сервера, возвращает ID и JSON-файл. |
| `/paste id:<id>` | Участники с правом **Администратор** | Добавляет скопированные роли и каналы на текущий сервер. |
| `/paste id:<id> wipe:true` | Участники с правом **Администратор** | Сначала удаляет существующие каналы и роли, затем клонирует (спросит подтверждение). |

## Что копируется, а что нет

**Копируется:** названия ролей, их права, цвет, отображение отдельно (hoist),
возможность упоминания и порядок; права `@everyone`; категории; текстовые,
голосовые, трибунные и форумные каналы вместе с темой, флагом NSFW, медленным
режимом, битрейтом и лимитом пользователей; а также права по ролям
(permission overwrites) на каждом канале.

**Не копируется:** сообщения, участники, персональные права конкретных
участников, инвайты, эмодзи, баны и любые секреты. Управляемые роли (роли
ботов, интеграций и бустеров), а также роли выше собственной роли бота
остаются нетронутыми — это правило прав самого Discord, а не ограничение кода.

## Установка

Сначала создайте приложение и бота на
<https://discord.com/developers/applications> → **Bot** → скопируйте токен.
Затем настройте нужную вам реализацию.

### 🐍 Python

```bash
cd python
cp .env.example .env          # затем откройте .env и вставьте свой токен
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

### 🟢 Node.js

```bash
cd node
cp .env.example .env          # затем откройте .env и вставьте свой токен
npm install
npm start
```

### Как добавить бота на сервер

Сгенерируйте ссылку-приглашение в разделе **OAuth2 → URL Generator**, выбрав
скоупы `bot` и `applications.commands`. Боту нужны права **Управление ролями**
и **Управление каналами** (выдайте **Администратора**, если хотите клонировать
сервер целиком вместе с ролями, у которых высокие права). Из-за иерархии ролей
в Discord поднимите роль бота **выше** тех ролей, которые он должен создавать
или удалять.

## Формат конфига

Конфиги хранятся в формате JSON в папке `configs/` соответствующей реализации
и адресуются 8-символьным ID. Битовые маски прав хранятся как десятичные
**строки**, а не числа: значения прав Discord превышают предел безопасных целых
чисел в JavaScript (2⁵³), поэтому при хранении в виде чисел они бы незаметно
искажались. Именно это и делает обе реализации взаимозаменяемыми.

```jsonc
{
  "schema_version": 2,
  "source_guild_name": "Мой сервер",
  "everyone_permissions": "104324673",
  "roles": [
    { "name": "Admin", "permissions": "1152921504606846975",
      "color": 16711680, "hoist": true, "mentionable": false, "position": 5 }
  ],
  "categories": [
    { "name": "Staff", "position": 0,
      "overwrites": [ { "role": "@everyone", "is_default": true,
                        "allow": "0", "deny": "1024" } ],
      "channels": [
        { "name": "general", "type": "text", "position": 0,
          "topic": "привет", "nsfw": false, "slowmode_delay": 5, "overwrites": [] }
      ] }
  ],
  "uncategorized_channels": []
}
```

## Примечания и ограничения

- Папки `configs/` исключены из git; относитесь к ID как к приватным данным.
- Используйте бота только на серверах, которыми владеете или управляете.
  Режим `wipe:true` необратим — бот спросит подтверждение, но отменить
  результат будет нельзя.
- На очень больших серверах возможны лимиты API Discord; обе библиотеки сами
  выдерживают паузы, так что большое клонирование просто займёт чуть дольше.
